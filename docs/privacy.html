Privacy and use

Updated 5 October 2026. Maintainer: Matěj Teplý (Majkey), majkeylab@gmail.com.

Repository data and tokens

This browser app sends your chosen repository and optional personal access token directly to GitHub's API to fetch issues, pull requests, and comments. The token is used in the authorization header. Export data is processed in the tab and packaged into a ZIP on your device. The maintainer has no application backend receiving this data.

The app does not use analytics, accounts of its own, cookies, or local storage. Token and results remain in the open tab. Clear the token field and close the tab when finished; your browser may offer session restoration. Delete downloaded archives separately and revoke a token in GitHub settings if it is no longer needed. Never send a token in a support request.

Services contacted by the website

GitHub Pages receives technical requests, including IP addresses, to serve and secure the site. GitHub's API receives the authenticated export requests. The ZIP library loads from cdnjs, operated by Cloudflare, which receives your IP address and ordinary request metadata when the page loads. See the GitHub privacy statement and Cloudflare privacy policy for their retention, international transfers, and privacy contacts.

Contact and privacy rights

Email addresses and messages sent to the maintainer are used to answer and document support requests, based on the legitimate interest in providing support. They are kept only while needed for that purpose or applicable legal obligations.

Contact the maintainer to request access, correction, deletion, restriction, or object to processing of information the maintainer holds. Portability applies where provided by law. You may complain to the Czech data protection authority or your local authority. GitHub and Cloudflare handle requests concerning their own records.

Permitted use and fees

Export only repositories you are authorized to access. Issues and comments may contain other people's personal information; keep exports secure and share them only where authorized. This tool has no purchases, subscriptions, or fees and no in-app refund process. The MIT license covers the source. Mandatory legal rights remain unaffected.

Python CLI

The separately installed CLI stores exports and optional raw JSON on your computer. Its attachment downloader can keep an authenticated browser profile. Delete those files and profiles locally when no longer needed. This website cannot erase them.
